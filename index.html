Langkah Deploy Aplikasi ke GitHub Pages

Agarkan seluruh warga RT/RW dan anggota Karang Taruna dapat membuka web ini dari HP masing-masing melalui tautan seperti https://username.github.io/17agustus/.

1

Buat Repository Baru

  • Buka akun GitHub di github.com/new.
  • Beri Repository Name: 17agustus.
  • Atur visibilitas ke Public.
  • Klik tombol Create repository.
2

Upload File index.html

  • Simpan kode HTML ini di komputer dengan nama index.html.
  • Di halaman GitHub repository tadi, pilih opsi uploading an existing file.
  • Upload file index.html lalu klik tombol Commit changes.
3

Aktifkan Fitur Pages

  • Klik menu tab Settings pada bagian atas repository.
  • Pilih menu Pages di bilah navigasi sebelah kiri.
  • Pada opsi Build and deployment (Branch), pilih branch main / master.
  • Klik tombol Save.
4

Sebarkan Link Web ke Warga

  • Tunggu 1–2 menit hingga proses build selesai.
  • Web 17-an sudah live di:
    https://[username-anda].github.io/17agustus/
  • Bagikan link di grup WhatsApp RT/RW dan Karang Taruna!
